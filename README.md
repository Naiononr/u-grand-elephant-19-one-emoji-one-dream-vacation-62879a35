> ⛵

A sailboat is not the transport *to* the holiday — it *is* the holiday. Days on the water, wind in the sail, nowhere to be: the dream vacation as weightlessness and elsewhere, not as a place everyone photographs. A white sail against blue water is a whole postcard in one glyph, and it points at one particular dream — sailing somewhere far away — rather than any generic holiday. It is also the fresh angle: a hundred entrants will send the beach, the palm tree or the plane, while the boat is the trip you dream about for years. One code point (U+26F5), no variation selector, unmistakable at any size.

## Run

```sh
node main.ts
```

Writes the emoji exactly, with no trailing newline, to `<MAKEFUN_OUTPUT_DIR or /output>/entry.txt`, mode 0644. Node 22.18 or later, standard library only, no network.
